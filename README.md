# Slot Booking AI

Simple parking-slot booking system with:
- Flask + SQLite backend API (`backend/`)
- React frontend app (`frontend/`)

## Quick Start
1. Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

2. Frontend
```bash
cd frontend
npm install
npm start
```
